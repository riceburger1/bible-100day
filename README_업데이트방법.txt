[주의울림 말씀읽고 쓰기 도전 100일 - PWA 업데이트 v2]

이번 업데이트 내용
1) 오늘의 말씀 복사 차단
2) 말씀 입력창 붙여넣기 / Ctrl+V / 드래그 붙여넣기 차단
3) 메인화면에 '양정중앙교회 청소년부'는 작게, '주의울림'은 크게 표시
4) 새 앱 아이콘: 펼쳐진 성경책 + '주의울림'
5) 연속 참여가 아니어도 다음 날 계속 참여 가능
6) 지난 날은 성공/실패, 오늘은 진행 중, 이후는 예정으로 표시
7) 성공 횟수 / 실패 횟수 / 남은 날 표시
8) Service Worker 캐시 버전 v2로 갱신

[중요]
기존 config.js는 건드리지 마세요.
Supabase URL과 Publishable key가 들어 있는 기존 config.js를 그대로 유지합니다.

[GitHub에 업데이트하는 방법]
1. GitHub에서 기존 말씀읽기 저장소로 들어갑니다.
2. Add file -> Upload files 를 누릅니다.
3. 이 폴더의 아래 6개 파일을 모두 업로드합니다.
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png
   - apple-touch-icon.png
4. 같은 이름의 기존 파일은 새 파일로 교체됩니다.
5. 아래 Commit changes 버튼을 누릅니다.
6. 기존 GitHub Pages 주소를 다시 엽니다.

[업데이트가 바로 안 보이면]
- 웹사이트를 완전히 닫았다가 다시 엽니다.
- 브라우저 새로고침을 1~2회 합니다.
- 설치된 PWA가 예전 아이콘을 계속 보이면 홈 화면의 기존 앱을 삭제한 뒤 사이트에서 다시 설치하면 새 아이콘이 적용됩니다.

[학생 기록]
기존 localStorage 키를 그대로 사용하므로 같은 기기의 성공 도장 기록은 업데이트 후에도 유지됩니다.
Supabase에 저장된 관리자 성공 기록도 그대로 유지됩니다.
